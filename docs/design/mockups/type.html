Type options for CSPNews

The same illustrative stories set four ways, including the Turkish letters ş, ğ, ı, İ and ç. The top line in each option is the headline face, the paragraph is the reading face. All are free Google Fonts with full Turkish support, so the site can self-host them. A custom-drawn CSPNews wordmark can sit on top of whichever you choose.
