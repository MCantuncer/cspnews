# Caught up

Three questions (or three things to remember), a week line, any open Hot story, and the next bulletin time.

## Quiz and week line (2026-11-15)

The "Three things to remember" list repeated the summaries the reader had just read, so a bulletin that has a `quiz` shows three questions instead. Each has three options. Tapping one shows right or not quite, marks the right option (a heavier border, never colour alone) and links back to the story. Nothing is scored, stored or shared: it is a quiet check of what stayed, not a game.

The questions are written with the bulletin (docs/publishing.md, "The quiz"), so there is no running cost. A bulletin without a quiz keeps the old list.

Above them sits the week line: seven days, Monday first, filled for each day on which the reader reached this screen. It is kept in this browser only (`cspnews:finished`), written hidden and shown once read, so a first visit shows nothing rather than an empty row. No streak count, no "don't break it" wording: it shows the week, and an empty day is only an empty day.
