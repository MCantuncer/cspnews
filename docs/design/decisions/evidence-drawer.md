# Evidence drawer

The **camp map**: one row per camp (government-aligned, opposition, independent, international) with a large count and each outlet by name, logo and a three-step reliability meter. An empty camp shows as an empty slot. Each camp's count is labelled as independent reports. An outlet that only republished another's text is listed without a meter and not counted, and the header total says so ("9 independent, 1 copy"), so it adds up to the evidence line's outlet count. A key under the list explains the meter.
