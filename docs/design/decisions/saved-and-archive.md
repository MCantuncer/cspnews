# Saved stories and earlier bulletins

## Saved stories

A story page has a quiet second button under Follow: "Save for later". Saving keeps the story's title and address in both languages in this browser (`cspnews:saved`, newest first, at most 100), so the Saved page can be drawn in the reader's language with nothing loaded and nothing sent anywhere. It is a reading list, not an account feature: it does not follow the reader to another device, and the page says so.

Follow and Save are different on purpose. Follow says "tell me when this moves" and changes the next bulletin; Save says "I want to read this later" and changes nothing else. No counts, no reminders, no "you have 12 unread".

The Saved page is `/saved` (`/tr/saved`). It is a plain list: section, title, and a Remove button. It is reached from the settings sheet that every page has, below the settings, so no new item is added to the header.

## Earlier bulletins

`/archive` (`/tr/archive`) lists every published bulletin by month and day, newest first, a chip per bulletin. It is built at publish time from the bulletins that exist, so it needs no script and grows with the site. It is linked from the same settings sheet. A month grid was left out: with up to four bulletins a day, a day cell cannot hold four honest links on a phone.
